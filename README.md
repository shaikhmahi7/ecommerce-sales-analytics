# E-Commerce Sales Analytics Dashboard

## Project Overview
Analyzed 100K+ real e-commerce orders from the Olist Brazilian 
dataset to uncover key business insights using Python, SQL, 
Excel and Power BI.

## Key Insights Found
- Orders with delivery delays over 10 days had 3x more 1-star reviews
- São Paulo generates 40% of total revenue
- 7.8% of all orders are delivered late
- Computers have highest avg order value at R$1,104
- Revenue grew from R$41K in 2016 to R$7.5M in 2018

## Tools Used
| Tool | Purpose |
|------|---------|
| Python | Data cleaning, EDA, Excel automation |
| SQL | KPI queries on 8 relational tables |
| Excel | 4-sheet automated report |
| Power BI | 3-page interactive dashboard |

## Dataset
[Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- 100K+ orders
- 8 relational tables
- Real transaction data from 2016-2018
